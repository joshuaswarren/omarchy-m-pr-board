How to read it. Blocking item: the first thing in the way, in this order: draft, conflicts, requested changes, failing check, workflow run waiting for a maintainer, missing review, running checks, branch behind, branch rules. RC blocker: yes when the PR carries a label named rc, rc-blocker, release blocker or blocker. Can merge now: GitHub reports the PR clean, with no conflicts and every required check and review satisfied; a repo that requires no review shows approvals as not required. Maclab: unknown, because maclab's job records are not public. Sections: the Omarchy M team, then people with an earlier merged PR in the same repo, then everyone else.
